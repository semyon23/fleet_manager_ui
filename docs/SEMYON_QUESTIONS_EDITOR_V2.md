## Что понял из скринов

### 1. Станции должны быть НЕ кружком

Сейчас и точка (waypoint), и станция (charge/parking) рисуются одинаковыми кружками. Ты хочешь чтобы станция выглядела иначе — квадратом, например. Согласен, так понятнее.

**Что сделаю:** waypoint = маленький кружок (как сейчас), станция = квадрат (или крупная плитка с иконкой типа станции). На карте с роботами оператор сразу видит где точка маршрута, а где зарядка/парковка.

### 2. Рисовать зону, а не точку

Пример из твоей голосовухи: **зона зарядки** — это не одна точка, а прямоугольная область куда робот заезжает и там паркуется. Логика: у нас есть тип **Zone** (уже есть в модели, но UI не сделан) — прямоугольник или полигон с типом (charge/queue/no-go).

**Что сделаю:** инструмент **Zone** в тулбаре. Зажимаешь мышь, тянешь — получается прямоугольник. Можно назначить тип (charging / parking area / no-go / interaction).

### 3. Координаты курсора — вверх и без тёмной плашки

Сейчас в левом нижнем углу — чёрная плитка с зелёным моно-текстом `-7.651 m, -5.444 m`. Мешает и выглядит криво.

**Что сделаю:** уберу нижнюю плашку. Координаты уже дублируются в правом верху меню-бара (`cursor · X.XX m, Y.YY m`) — оставлю только там.

### 4. Масштабирование

Ты говорил "нужно что-то придумать со скалированием". Уточни что именно не так:

- **(а)** сетка при zoom-in становится слишком редкой / густой?
- **(б)** точки/станции меняют размер при zoom (сейчас нет — `scalingObjects: false`)?
- **(в)** карта загружается не под размер экрана?
- **(г)** что-то другое?
